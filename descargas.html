Para el área de sistemas

Instalación en toda la sala de cómputo

Instalación desatendida en los tres sistemas operativos. Un solo comando por equipo o por directiva de grupo.

Windows

:: Instalación silenciosa para todos los usuarios
setup-x64.exe /VERYSILENT /NORESTART ^
  /MERGETASKS=!runcode,addcontextmenufiles,addtopath

Descarga el instalador de sistema y despliégalo por directiva de grupo o con tu herramienta de gestión de equipos.

macOS

# Descomprimir e instalar en el equipo
unzip -q VCodePro-darwin-universal.zip \
  -d /Applications/
xattr -dr com.apple.quarantine \
  /Applications/VCodePro.app

Distribuible con tu sistema de gestión de dispositivos móviles.

Linux

# Debian y Ubuntu
sudo apt install ./vcodepro-x64.deb

# Fedora, RHEL y SUSE
sudo rpm -i vcodepro-x64.rpm

En distribuciones con Snap también funciona sudo snap install code --classic.

Licencia del colegio. Después de instalar, activa una sola vez la clave institucional en el portal de licencias. Los equipos de la sala heredan la activación desde el archivo de configuración del aula.

Dudas frecuentes

Sobre la descarga y la instalación

¿Tiene algún costo descargar el editor?

No. La descarga y el uso del editor son gratuitos. La licencia se necesita para el modo aula, las rúbricas del Bachillerato Internacional, el estudio de agentes y el soporte institucional.

¿Cuál instalador de Windows debo elegir?

El instalador de usuario no pide permisos de administrador y es ideal para un computador personal. El instalador de sistema instala para todos los usuarios del equipo y es el indicado para salas de cómputo.

¿Funciona sin conexión a internet?

Sí. El editor, los proyectos y las rúbricas funcionan sin conexión. El asistente de inteligencia artificial y la sincronización del modo aula requieren red; cuando vuelve la conexión, todo se sincroniza solo.

¿Cómo se actualiza?

El editor avisa cuando hay una versión nueva y se actualiza en segundo plano. En salas de cómputo el área de sistemas puede fijar la versión y controlar cuándo se actualiza todo el laboratorio.

¿Puedo instalarlo en el computador de mi casa?

Sí. Con la licencia Escuela o de Sitio, cada estudiante y docente puede usar su puesto asignado en el equipo del colegio y en uno personal.

¿Listo para licenciar tu colegio?

Compara los planes Personal, Escuela y Licencia de Sitio, y calcula el valor exacto según el número de licencias que necesitas.
